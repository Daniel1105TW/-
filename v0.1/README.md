# 班級簽到簿

給國小班級使用的「簽到 + 聯絡簿」系統。教師在一台電腦啟動伺服器，教室內其他電腦、平板或手機透過區域網路開啟學生端即可使用(同網路下皆可)。

## 功能一覽

- 學生端左側是簽到名單，右側是今日聯絡簿。

- 點擊學生姓名會依序切換：`未簽到 → 簽到 → 請假 → 外務 → 未簽到`。
- 簽到狀態依日期保存，每天是獨立紀錄。

- 後台可更改班級名稱、年級、配色主題與注音顯示。
- 後台可新增、停用學生，也可重新使用已停用的座號。

- 支援匯入 `.xlsx` 學生名單，匯入前會先預覽。
- 後台可新增、刪除聯絡簿內容。

- 後台可一鍵清除今天的簽到狀態。
- SQLite 資料庫保存在本機，不需要雲端帳號。

## 開始前準備

請先安裝：

1. Node.js 20.9 或更新版本：<https://nodejs.org/>
2. 本專案資料夾：`簽到+連絡簿系統`

在 VS Code 開啟本資料夾後，開啟終端機。Windows 可使用 PowerShell。

## 第一次啟動

在專案資料夾執行：

```powershell
npm install
npm run dev -- --hostname 0.0.0.0
```

看到 `Ready` 後，代表伺服器已啟動。

在啟動伺服器的電腦開啟：

- 學生端：<http://localhost:3000>
- 教師後台：<http://localhost:3000/admin>

第一次進入後台時，系統會要求設定密碼。若暫時不想設定密碼，啟動後可直接使用後台；正式在教室使用時建議設定密碼。

## 讓其他裝置連線

### 1. 查詢主機 IP

在啟動伺服器的 Windows 電腦另開一個 PowerShell，執行：

```powershell
ipconfig
```

找到目前使用中的網路介面，在 `IPv4 Address` 或「IPv4 位址」看到類似 `192.168.1.20` 的數字。

### 2. 在其他裝置開啟

假設主機 IP 是 `192.168.1.20`，其他裝置開啟：

```text
http://192.168.1.20:3000
```

教師後台則是：

```text
http://192.168.1.20:3000/admin
```

所有裝置必須連接同一個 Wi-Fi 或區域網路。請不要把這個系統直接暴露到公開網際網路。

### 3. 如果其他裝置打不開

- 確認伺服器視窗仍顯示 `Ready`，不要關閉它。
- 確認兩台裝置連接同一個網路。

- 確認網址中的 IP 是啟動伺服器那台電腦的 IPv4 位址。
- Windows 防火牆若跳出提示，請允許 Node.js 在「私人網路」通訊。
- 若仍無法使用，請先暫時確認 Windows 網路設定沒有啟用「公用網路」隔離。

## 後台操作

開啟 `/admin` 後，可以依下列順序設定：

### 班級名稱

在「班級名稱」輸入名稱，例如 `向日葵班`，按「儲存名稱」。學生端標題會顯示為「向日葵班簽到簿」。

### 畫面設定

- **年級**：選擇一年級至六年級。
- **配色主題**：選擇草地清新、暖陽橘紅或天空藍綠。

- **啟用注音**：開啟後，學生姓名與前台聯絡簿的標題、內容會在國字旁顯示注音。

修改後按「儲存畫面設定」，學生端通常會在幾秒內同步更新。

### 新增或停用學生

在學生管理區輸入座號與姓名，按「新增學生」。

停用學生不會刪除過去的簽到紀錄。如果之後再次新增相同座號，系統會重新啟用原本的資料並更新姓名。

### 匯入 Excel 名單

Excel 第一列請使用欄位名稱，至少包含：

| 座號 | 姓名 |
| ---: | --- |
| 1 | 王小明 |
| 2 | 林小花 |
| 3 | 陳品妤 |

操作方式：

1. 將檔案存成 `.xlsx` 或 `.xls`。
2. 在後台「學生名單」選擇「匯入 Excel 名單」。
3. 確認畫面上的預覽內容。
4. 確定正確後按「確認匯入」。

系統支援的欄位名稱包括：`座號`、`座次`、`seatNumber`，以及 `姓名`、`name`。空白姓名或無效座號會被排除；同一座號會更新並啟用既有學生資料。

### 聯絡簿

在「聯絡簿」區輸入標題與內容，按「新增聯絡簿」。學生端只顯示今天日期的內容。啟用注音後，聯絡簿文字也會顯示注音。

刪除聯絡簿前請確認內容，刪除後無法從畫面復原。

### 重置今日簽到

按「重置今日簽到」並確認後，只會清除今天的簽到狀態，不會影響其他日期的紀錄、學生名單或聯絡簿。

## 每日使用流程

1. 啟動伺服器。
2. 教師先開啟 `/admin`，確認日期、班級名稱與學生名單。

3. 學生端開啟首頁，依學生到校情況點擊姓名。
4. 需要更正時，繼續點擊該姓名直到正確狀態。
5. 教師在後台新增當日聯絡簿內容。
6. 下課或放學後可備份資料庫。

## 停止與重新啟動

開發伺服器正在執行時，在該終端機按：

```text
Ctrl + C
```

下次使用再執行：

```powershell
npm run dev -- --hostname 0.0.0.0
```

## 資料與備份

主要資料庫檔案是：

```text
data/attendance.sqlite
```

備份時請先停止伺服器，再複製整個 `data` 資料夾到 USB、外接硬碟或其他安全位置。這個資料庫包含學生名單、簽到紀錄、聯絡簿與畫面設定。

目前後台密碼只保存在伺服器執行期間的記憶體中，重新啟動伺服器後會回到無密碼狀態；這是目前版本的限制。若系統要長期或公開部署，請先限制在可信任的區域網路中使用。

## 常見問題

### 頁面顯示「目前無法連線」

確認 `npm run dev -- --hostname 0.0.0.0` 的終端機仍在執行，並重新整理頁面。若從其他裝置連線，請檢查 IP 與 Windows 防火牆。

### 後台看不到新增的學生

重新整理後台。若座號已存在，系統會嘗試重新啟用原本的停用資料；若仍失敗，確認座號是正整數且姓名不是空白。

### Excel 匯入沒有資料

確認第一列是欄位名稱，且欄位名稱為 `座號` 與 `姓名`。確認每一列的座號是數字、姓名不是空白，並使用第一個工作表。

### 注音顯示不完整

確認後台的「啟用注音」已儲存，並重新整理學生端。英文、數字與標點符號不會轉成注音；中文會依讀音顯示注音。

### 忘記後台密碼

目前版本的密碼會在伺服器重新啟動後清除。停止伺服器，再重新執行啟動指令即可回到無密碼狀態。
